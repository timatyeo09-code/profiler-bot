BIL INTELLIGENCE PORTAL - VERCEL PROJECT

Upload these items to the ROOT of your GitHub repository:
- index.html
- profiler.html
- vercel.json
- api/profile.js

Required Vercel environment variable:
ANTHROPIC_API_KEY = your private Anthropic API key

Optional environment variable:
ANTHROPIC_MODEL = claude-sonnet-4-5

After committing to the main branch, Vercel redeploys automatically.
Open The Profiler and run a short test observation.
